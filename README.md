# Hotfix

### \(백슬래시) 키로 채팅 창을 열 수 있습니다.

**Hotfix 모드**는 게임 안에서 사용할 수 있는 AI 에이전트 모드입니다. 인게임에서 AI 에이전트에게 지시를 내려서 림월드를 입맛대로 고치거나 수정해보세요.

저는 모드를 450개 이상 사용하는 헤비 모드팩 유저입니다. 헤비하게 모딩된 림월드를 플레이하다보면 원인을 찾기 어려운 버그들이 종종 발생했었습니다. 이 모드는 그런 모드들간의 사소한 호환성 문제를 LLM의 도움으로 해결하고자 개발되었습니다.

AI는 실수를 할 수도 있으니 항상 유의하여 사용하세요.

## 주요 기능

- **인게임에서 실행되는 코딩이 가능한 AI 에이전트**: AI가 실행 중인 어셈블리를 분석하여 게임 정보를 파악할 수 있습니다. 추가로 게임을 알아서 조작할 수도 있습니다. 
- **서브 모드**: 서브 모드는 이 모드에서 관리하는 별도의 모드 단위입니다. AI 에이전트는 당신이 요청한 새로운 기능이나 버그 수정을 서브 모드로 만듭니다. 단순한 Harmony 패치부터 시작해서 XML 기반의 컨텐츠 모드나 XML 패치 모드, 복잡한 기능을 가진 모드까지 만들 수 있습니다. 모드 설정창에서 켤지 말지를 결정할 수 있습니다.

## 사용 예시

- (여기에 아무 상황 입력)에서는 어떤 일이 발생하는지 알려주세요 -> AI 에이전트가 게임 정보를 기반으로 실제 동작 과정을 설명해줍니다.
- (여기에 게임 로직 입력)을 (여기에 내 입맛 입력)처럼 되도록 바꿔주세요 -> AI 에이전트가 게임
- (여기에 아직 1.7을 지원하지 않는 모드 입력)을 1.7에 호환되게 해주세요 -> AI 에이전트가 해당 모드를 수정하여 1.7에 호환되도록 작업해줍니다.
- (여기에 작은 기능을 가진 모드 입력)을 만들어주세요 -> AI 에이전트가 게임 파일을 까보고 요청에 부합하는 서브 모드를 만들어줍니다.
- (여기에 CE에 호환되지 않는 모드 입력)을 CE에 호환되게 해주세요 -> AI 에이전트가 모드 파일을 까보고 서브 모드를 만들어줍니다.
